PHARMACOLU TRADER — starter web app

HOW TO RUN
1. Extract this ZIP.
2. Open index.html in a modern browser, or upload the folder to a static web host.
3. Internet access is needed for the optional CoinGecko crypto-price request.

FEATURES
- Demo account with $10,000 virtual balance.
- Simulated BUY and SELL positions.
- Position closing, P/L, and trade history.
- Forex and crypto market watch.
- Attempts to retrieve Bitcoin and Ethereum spot prices from CoinGecko.
- Clear labels where data is sample/indicative.
- Real Trading screen is intentionally disabled.

IMPORTANT LIMITATIONS
- This is a prototype, not a regulated brokerage platform.
- Demo trading calculations are simplified and do not model spreads, fees, slippage, leverage, or market execution.
- Forex quotes are illustrative sample values, not live quotes.
- Crypto API availability, rate limits, and browser/network restrictions may affect updates.
- No deposits, withdrawals, custody, account verification, or real orders are implemented.
- Do not enter payment details or send money through this prototype.

NEXT DEVELOPMENT STEPS
A production platform needs a backend, secure authentication, a licensed/eligible broker relationship, broker-approved API integration, security testing, legal review, and compliance controls. Never put broker secrets or API keys in browser JavaScript.
